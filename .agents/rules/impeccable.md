# Impeccable Craft Rules

Whenever designing, implementing, or reviewing user interfaces:
- Avoid classic AI design tells: overused generic fonts, washed-out gray text on colored backgrounds, nested cards within cards, and zero-offset neon glow shadows.
- Ensure container padding is comfortable (minimum 8–16px inset).
- Maintain distinct typographic scale steps (heading sizes should be >= 1.25x body size).
- Run `npx.cmd impeccable detect <target>` to ensure zero anti-patterns prior to completing major UI work.
