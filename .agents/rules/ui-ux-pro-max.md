# UI/UX Pro Max Rules

When working on any frontend user interface, layout, styling, or UX component:
- Follow the guidelines in `.agents/skills/ui-ux-pro-max/SKILL.md`.
- Use `python .agents/skills/ui-ux-pro-max/scripts/search.py` to consult design palettes, font pairings, and UX best practices.
- Adhere to the Pre-delivery Checklist:
  1. Contrast ratio >= 4.5:1.
  2. Touch target >= 44x44px.
  3. SVG icons only (no emojis as UI icons).
  4. Responsive across 375px, 768px, 1024px, 1440px.
  5. Visible focus rings for keyboard navigation.
  6. Smooth transitions with reduced-motion support.
